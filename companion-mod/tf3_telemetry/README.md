# TF3 Live Telemetry & Cockpit Companion Mod

Native in-game engine hook for **Transport Fever 3** that streams real-time vehicle, line, and financial telemetry to the external web cockpit dashboard.

---

## 🚀 Installation (English)

1. Copy the entire `tf3_telemetry` folder into your Transport Fever 3 mods directory:
   * **Steam:** `<SteamLibrary>/steamapps/common/Transport Fever 3/mods/`
   * **Release / Standalone:** `<GameFolder>/Transport Fever 3/mods/release/`
2. Launch the game or load your savegame.
3. Enable the mod **"TF3 Live Telemetrie & Cockpit"** in your savegame mod settings.
4. Ready! The mod now automatically streams live ticks to the telemetry dashboard.

---

## 🇩🇪 Installation (Deutsch)

1. Kopiere den gesamten Ordner `tf3_telemetry` in dein Transport Fever 3 Mod-Verzeichnis:
   * **Steam:** `<Steam-Bibliothek>/steamapps/common/Transport Fever 3/mods/`
   * **Manuelle / Release-Version:** `<Spielverzeichnis>/Transport Fever 3/mods/release/`
2. Starte das Spiel oder lade deinen Spielstand.
3. Aktiviere den Mod **"TF3 Live Telemetrie & Cockpit"** in den Spielstand-Einstellungen.
4. Fertig! Der Mod überträgt nun automatisch alle Ticks an das Telemetrie-Dashboard.
